# 01 · 产品需求文档（PRD）

## 1. 一句话定位

**AI Website Growth Agent（SEO + GEO + Analytics + Execution）**：持续理解一个网站，在传统搜索与生成式引擎两侧发现增长机会，制定方案，协助或自动执行优化，并根据数据闭环再优化。

## 2. 问题陈述

传统 SEO 工具回答的是：

> 「你的网站哪里有问题。」

用户真正需要的是：

> 「我现在应该做什么，才能让网站获得更多流量和客户？」

差距在于：发现问题 ≠ 发现机会 ≠ 可执行行动 ≠ 结果闭环。

## 3. 产品目标

| 目标层级 | 描述 |
| --- | --- |
| 核心 | 每天给出「下一步做什么」，并可协助执行 |
| 业务 | Traffic → Engagement → Conversion |
| 体验 | 像一位专职增长员工，而不是一份静态报告 |

## 4. 非目标（V1）

- 不做全自动无人值守改生产（放到 V3/V4）
- 不做完整广告投放 / SEM 管理
- 不做多语言 SEO 全覆盖（可后续扩展）
- 不做通用爬虫 SaaS；聚焦「单站深度增长」

## 5. 目标用户

| 角色 | 诉求 |
| --- | --- |
| 独立开发者 / Indie Hacker | 自己没时间天天看 SEO，需要每日行动清单 |
| 小型 SaaS / 内容站 | 需要关键词机会、内容缺口、转化建议 |
| 增长负责人 | 需要把 GSC/GA/站点数据合成「机会」而非图表 |

首发策略：先服务自己的站点，再开放给同类用户。

## 6. 核心价值主张

1. **从发现问题 → 发现机会**  
   不只说「About 缺 description」，还判断「About 搜索价值低，不如补 3 篇产品内容页」。

2. **从分析 → 行动**  
   问题 → 原因 → 方案 → 生成内容 → 用户确认 → 执行 → 监控。

3. **从 SEO → SEO + GEO → 网站增长**  
   覆盖技术 SEO、**GEO（AI 回答可见性）**、内容、关键词、内链、行为、转化、性能。  
   成功不只看蓝链流量，也看品牌/页面是否进入生成式回答的引用池。

## 7. 用户旅程

### 7.1 接入

```text
输入网站 URL
  → 连接 GSC / GA4 / Sitemap / robots
  → （可选）连接 GitHub / CMS
  → 首次 Website Audit
```

### 7.2 日常使用

```text
打开 Dashboard
  → 今日增长建议（高/中/低优先级）
  → 查看机会详情
  → 生成优化方案
  → 确认执行（V1：导出/复制；V3：PR）
  → 观察指标变化
```

## 8. 功能范围分层

### P0（V1 必须）

- 网站接入与基础爬取
- 技术 SEO 扫描与评分
- **GEO Readiness 扫描与评分**（答案块、FAQ/Schema、实体、AI bot / llms.txt 等）
- GSC + GA4 数据拉取与解读
- 关键词机会识别
- 内容缺口提示（含「答案型内容」缺口）
- 「今日增长建议」日报页（可含 GEO 卡片）
- 核心页面：Dashboard / 网站分析 / 关键词机会 / 内容机会 / **GEO** / 增长建议

### P1（V2）

- 竞品跟踪
- 内容大纲与草稿生成
- 页面优化 / 内链建议可落地到文案级
- **GEO Answer Presence**：目标问题集上的品牌/URL 引用探测

### P2（V3）

- GitHub 集成、改代码、跑测试、开 PR

### P3（V4）

- 批准后自动部署、效果归因、策略自动调整

## 9. 成功指标

| 指标 | 说明 |
| --- | --- |
| 日活建议采纳率 | 用户点击「生成方案 / 标记已处理」占比 |
| 机会→执行转化率 | 机会卡片最终产生实际改动的比例 |
| 实验站自然流量 | 接入后 30/90 天 organic 变化 |
| GEO Readiness 提升 | 关键页 geo 分与结构化/FAQ 覆盖率 |
| AI 引用出现率（V2） | 目标 prompt 集中品牌/域名被提及比例 |
| 建议准确度 | 人工抽检：建议是否「值得做」 |

## 10. 风险与约束

- GSC/GA API 配额与 OAuth 复杂度
- 爬虫对目标站的礼貌与合规
- AI 幻觉导致错误 SEO 建议 → 需规则引擎 + 引用证据
- 自动改代码风险 → 必须人工确认门禁（V3 起）
- 关键词搜索量等第三方数据成本

## 11. 产品原则

1. **机会优先于分数**：评分是入口，机会是产品。
2. **有证据再说话**：每条建议绑定 URL、指标、对比样本。
3. **可执行粒度**：建议必须落到页面、字段、动作。
4. **人在环路**：默认确认后执行；全自动是可选能力。
5. **闭环**：没有反馈回路的建议不算完成。
